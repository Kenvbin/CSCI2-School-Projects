# Computer Science 2 / Spring 2026

This repo is a collection of my C++ programming assignments, labs, and class examples from when I took CSCI 2.

## Assignments

### Week 1
- [Class Example - Bank account](assignments/week-01/bank-account-example/Week1_2-21-26/BankAccount.cpp) - Demonstrates classes, constructors, getters and setters, and depositing or withdrawing money from a bank account.
- [Lab - Rectangle class](assignments/week-01/lab/Week1Lab/Rectangle.cpp) - Creates a Rectangle class with length and width validation, getters and setters, and an area calculation.
- [Homework - Mortgage payment calculator](assignments/week-01/homework/Week1Hw/main.cpp) - Uses a class to calculate monthly mortgage payments and the total amount paid from the loan amount, interest rate, and term.

### Week 2
- [Class Example - Rectangle and box inheritance](assignments/week-02/inheritance-example/Week2_2-28-26/W2_ExampleInheritance.cpp) - Demonstrates inheritance by extending a Rectangle class into a Box class to calculate its volume.
- [Lab - Employee and production worker](assignments/week-02/lab/Week2Lab/Week2Lab.cpp) - Uses inheritance to create employee and production-worker classes, storing shift information and calculating pay from hours worked.

### Week 3
- [Lab - Fraction operator overloading](assignments/week-03/lab/Week3Lab/main.cpp) - Creates a Fraction class that overloads input, output, multiplication, division, and comparison operators.
- [Homework - Student and undergraduate classes](assignments/week-03/homework/Week3HW/Week3HW.cpp) - Uses abstract classes and virtual functions to store undergraduate information and estimate age at graduation.

### Week 4
- [Homework - Preferred customer discounts](assignments/week-04/homework/Week4HW/main.cpp) - Uses inheritance to track customer purchases and calculate discount levels based on total spending.

### Week 5
- [Lab - Linked list basics](assignments/week-05/lab/Week5Lab/main.cpp) - Implements a linked list with operations for adding nodes to the beginning or end, deleting nodes, and displaying values.
- [Homework - Day-of-year converter](assignments/week-05/homework/Week5HW/main.cpp) - Converts a day number from 1 to 365 into a month and day using a DayOfYear class.

### Week 6
- [Lab - Linked list operations](assignments/week-06/lab/Week6Lab/main.cpp) - Expands linked list functionality with insertion at a position, deletion, appending, and counting nodes.
- [Lab 2 - Integer stack](assignments/week-06/lab-02/Week6Lab2/main.cpp) - Implements an array-based integer stack with push, pop, peek, search, and a copy constructor.
- [Homework - Linked list size and search](assignments/week-06/homework/Week6HW/main.cpp) - Builds a linked list that appends values, counts its nodes, and searches for a specified value.

### Week 7
- [Homework - Student records linked list](assignments/week-07/homework/Week7HW/main.cpp) - Stores student names and grades in a linked list with options to view, edit, and delete student records.

### Week 8
- [Lab - Math stack](assignments/week-08/lab/Week8Lab/main.cpp) - Creates a stack that performs arithmetic on its values, including addition, subtraction, multiplication, and division.
- [Homework - Balanced parentheses](assignments/week-08/homework/Week8Hw/main.cpp) - Uses a stack to check whether the opening and closing parentheses in a string are balanced.

### Week 9
- [Lab - Uppercase conversion queue](assignments/week-09/lab/Week9Lab/main.cpp) - Enqueues characters from a string, then dequeues them to build an uppercase version of the text.
- [Homework - Airport check-in queue](assignments/week-09/homework/Week9HW/main.cpp) - Simulates passengers arriving for airport check-in using a dynamic queue and reports passenger and wait-time statistics.

### Week 10
- [Lab - Test score exceptions](assignments/week-10/lab/Week10Lab/main.cpp) - Calculates average test scores from an array and throws an exception when a score is outside the valid range.
- [Homework - Date formatting and validation](assignments/week-10/homework/Week10HW/main.cpp) - Displays a date in three formats and uses exceptions to handle invalid month or day values.

### Week 11
- [Lab - Ice cream order exceptions](assignments/week-11/lab/Week11Lab/main.cpp) - Validates an ice cream order with one to three scoops and a flavor choice, throwing exceptions for invalid entries.
- [Homework - Comparing sentences with queues](assignments/week-11/homework/Week11HW/main.cpp) - Uses character queues to compare two user-entered sentences and report whether they match.

### Week 12
- [Lab - Recursive sum and multiplication](assignments/week-12/lab/Week12Lab/main.cpp) - Uses recursion to sum the values of an array and multiply two integers through repeated addition.
- [Homework - Recursive character counter](assignments/week-12/homework/Week12HW/main.cpp) - Recursively counts how many times a specified character appears in a string.

### Week 13
- [Lab - Computer parts binary search tree](assignments/week-13/lab/Week13Lab/main.cpp) - Stores computer parts in a binary search tree and searches for a part by its ID number.
- [Homework - Counting binary tree nodes](assignments/week-13/homework/Week13HW/main.cpp) - Adds functions to a binary search tree for counting total nodes and leaf nodes.

### Week 14
- [Lab - Max-heap insertion](assignments/week-14/lab/Week14Lab/main.cpp) - Implements max-heap insertion, swapping values upward to preserve heap order after each new entry.
- [Homework - Library book binary search tree](assignments/week-14/homework/Week14HW/main.cpp) - Stores book details in a binary search tree and demonstrates adding, finding, and removing books by ISBN.
